# Project Requirements

I want to create a multi user notes application.

- This will be a Ruby on Rails application based on the Gemfile included in this folder.

- This is to be a multi user application.

- Use the `authentication-zero` library for user management.

- Use the `rolify` library for role management.

- Use the `cancancan` library for the authorisation of resources.

- There will be a single database for the users.

- Each user will have their own database for their notes. When a new user is created a database will also be created for that user.
