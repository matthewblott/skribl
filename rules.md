# Rules 

## General Programming

Always do the following:
Use tabs over spaces.
Use 2 spaces for tabs for all programming languages.
Ask for clarification if ever unsure, never assume anything.
Use DRY and SOLID principles as much as possible.

## CSS Programming

Always do the following:
Use Tailwind.
Use Tailwind's apply method for repeating styles on elements like button, input and a tags.

## Ruby Programming

Always do the following:
Use the latest version of Ruby (currently 3.4).
Indent public and private methods using the same format.
Use single line Ruby methods where possible.

## Rails Programming

Always do the following:
Use the latest version of Rails (currently 8.0).
Use popular and well maintained gems.

Never do the following:
Upgrade the Rails version unprompted.
